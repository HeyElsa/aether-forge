## Install

> **Note:** Aether Forge is not yet published to PyPI. Until then, install directly from GitHub.

### Install from GitHub (recommended for now)

```bash
# Full install with all extras
pip install 'aether-forge[all] @ git+https://github.com/HeyElsa/aether-forge.git'

# Or clone and install locally
git clone https://github.com/HeyElsa/aether-forge.git
cd aether-forge
pip install -e '.[all]'
```

### Install from PyPI (coming soon)

```bash
# Full install — wallet + memory + encryption + A2A + MCP
pip install 'aether-forge[all]'

# Or pick extras individually
pip install 'aether-forge[wallet]'      # Real OWS wallets across 9 chains
pip install 'aether-forge[knowledge]'   # MemPalace long-term memory layer
pip install 'aether-forge[security]'    # cryptography for encrypted backups
pip install aether-forge                # Core only — heuristic planner
```

Requires **Python 3.12+**. Single core dependency (`jsonschema`).

> **Using TypeScript / JS instead?** The companion [`@aether-forge/sdk`](/docs/reference/typescript-sdk) package validates the same artifacts and parses planner output from Node, browsers, and edge runtimes. Jump to [Use from TypeScript](#use-from-typescript) below.

## Choose Your LLM

Aether Forge auto-detects the best available LLM in this priority:

1. **Anthropic** — `claude-sonnet-4.5`, `claude-opus-4-6`
2. **OpenAI** — `gpt-4o`, `gpt-4.1`
3. **Google** — `gemini-2.5-flash`
4. **OpenRouter** — any of 200+ models
5. **Ollama** (local, free, private) — only when no cloud key is set, unless `AETHER_FORGE_ALLOW_OLLAMA_AUTODETECT=1`
6. **Heuristic** — rule-based fallback (no LLM needed)

Set your API key for whichever provider you want:

```bash
# Option A — Anthropic
export ANTHROPIC_API_KEY=sk-ant-...

# Option B — OpenRouter (200+ models)
export OPENROUTER_API_KEY=sk-or-v1-...

# Option C — Local Ollama (free, used only when no cloud key is set)
ollama pull gemma4:latest
```

## Generate Your First Agent

```bash
forge generate-fast \
  --name "My First Agent" \
  --idea "ETH swing trader" \
  --wallet --autonomous \
  --output ./my-agent
```

```
[planner] auto-detected: mode=anthropic model=claude-sonnet-4.5
  Wallet: 0xE8D0...081d5 (Base)
  Attestation: self-attested
Generated at ./my-agent
```

This creates a complete agent directory with:
- `agent-spec.json` — agent contract
- `capability-manifest.json` — declared capabilities
- `policy-bundle.json` — safety rules
- `scenario-pack.json` — test scenarios
- `aether-forge.json` — runtime config (LLM, data sources, MCP)
- `wallet.json` — wallet addresses
- `attestation.json` — EIP-712 self-attestation

## Validate

```bash
forge validate ./my-agent
# Validated 5 artifacts in ./my-agent
```

Every generated agent ships with a `Makefile`, `tests/test_agent.py` smoke test, `Dockerfile`, and `.env.example` — so the next steps are one command each:

```bash
cd ./my-agent
make test         # green out-of-box: artifacts validate + scenarios meet expectations
make eval-pack    # run the scenario pack against the runtime
make doctor       # 8-point diagnostic round-trip
make help         # see all available targets
```

## Run

```bash
# Paper trading — real prices, simulated orders
forge run ./my-agent --mode paper --auto-approve

# With self-improvement and knowledge layer
forge run ./my-agent --mode paper --auto-approve --autoresearch --knowledge

# With A2A server for inter-agent communication
forge run ./my-agent --mode paper --auto-approve --a2a-port 9001
```

## Use from TypeScript

For JS / TS / browser / edge consumers, the companion `@aether-forge/sdk` package ships validators, generated types, and the cross-language planner-output parser. It conforms to the same JSON schemas as the Python core — every artifact valid under `forge validate` is also valid under the TS validators, enforced by CI conformance fixtures.

```bash
npm install @aether-forge/sdk
# or: bun add @aether-forge/sdk
# or: pnpm add @aether-forge/sdk
```

```ts
import {
  validateAgentSpec,
  parsePlannerOutput,
  assertValid,
  PlannerParseError,
} from "@aether-forge/sdk";

// Validate an artifact loaded from disk, S3, or anywhere else.
const spec = assertValid(validateAgentSpec(jsonFromDisk));

// Run a raw LLM response through the same recovery logic the Python
// reference uses (code-fence stripping, reasoning preambles,
// balanced-brace scan with string-literal awareness).
try {
  const plan = parsePlannerOutput(rawLlmResponse);
} catch (err) {
  if (err instanceof PlannerParseError) {
    // fall back to a heuristic planner
  }
}
```

v0.1.0 ships validators, generated types for all 19 JSON schemas, the planner-output parser, and TypeScript interfaces mirroring every Python Protocol. It is interface-only by design — the runtime tick loop, policy gate, memory stores, and signer reference implementations stay Python-side until cross-language usage data justifies a port. See the full [TypeScript SDK reference](/docs/reference/typescript-sdk).
